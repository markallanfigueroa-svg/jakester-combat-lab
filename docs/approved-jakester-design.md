# Officer Jakester — Approved Character and Combat Target (2026-11-14)

## Approved canonical appearance
The two user-provided reference illustrations (full-body combat pose and six-stage straight-punch sequence) are the definitive visual target. No redesign. Muscular anthropomorphic pig sheriff, reddish-pink skin, short spiked dark hair, full dark beard, expressive snout and ears, black/orange plaid rolled-sleeve shirt, dark tactical vest with pouches, radio, gold sheriff star, fingerless gloves, dark cargo trousers, holster, knee pads, and black heavy boots. Default has no cowboy hat or navy uniform. Preserve proportions and outfit details closely; do not replace with a blocky cartoon.

## Combat and animation
Natural shoulder/torso/hip rotation, weight transfer, full arm extension, follow-through, and return to guard. Straight punch phases: ready/guard -> wind-up -> drive forward -> full extension/impact -> follow-through -> recover. Existing left jab, right cross, sequential left-right combo, heavy (shorten excessive reach). Add front kick, roundhouse kick, crouch punch, low sweep, jump, jumping punch, jumping kick, grabs/throws, standing/crouch block, backstep, sidestep, and a timing-based block reversal ending in a spinning back kick with stagger/knockdown on the training opponent.

## Implementation boundaries
Standalone public jakester-combat-lab is the test environment. Do not modify main Battle for Oinkaverse or PreOink. Build a genuine articulated 3D rig and animation system; the existing Canvas 2D v3 is only a placeholder and must not be represented as a completed 3D character. Use free/open-source tools first. Validate mobile iPhone Safari performance, animation timing, and collision feedback before claiming a playable 3D build. Keep references with the user's original assets when available; this document does not itself contain or convert those illustrations into a 3D mesh.
